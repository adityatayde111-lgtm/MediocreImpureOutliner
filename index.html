    Direct mapping is simplest but conflicts when different blocks share an index. Fully associative eliminates conflict misses via exhaustive tag matching. Set associative balances hardware complexity and hit rates.

    Vocabulary & Concepts

    Tag
    Upper address bits stored alongside the cache line to verify whether it holds the requested memory block.
    Index / Set
    Middle address bits that select the specific cache line (direct-mapped) or set of ways (set-associative).
    Offset
    Lowest address bits that pinpoint the exact byte inside the fetched block. Offset never affects hit or miss.
    Hit
    The requested address block is already present in the designated set with a valid matching tag.
    Miss (LRU)
    Block not in cache. It is fetched from main memory, evicting the Least Recently Used line if the set is full.
